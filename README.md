# 🛡️ Búnker SRE

Proyecto de infraestructura profesional que implementa un sistema completo de despliegue, monitoreo y seguridad siguiendo estándares de la industria.

## 🎯 Objetivo

Construir un laboratorio SRE local replicable en la nube con un solo comando.

## 🧱 Stack Tecnológico

| Área | Tecnología |
|------|-----------|
| Sistema Operativo | Ubuntu 24.04 (WSL2) |
| Contenedores | Docker + Docker Compose |
| Monitoreo | Prometheus + Grafana |
| Automatización | Python 3.12 |
| Seguridad | Trivy + fail2ban |
| CI/CD | GitHub Actions |
| Infraestructura como Código | Terraform |
| Control de versiones | Git + GitHub |
